ҚОҢЫРАУ — мектеп пен отбасы байланысы (оқу жобасы)

=====================================================
1. ЖИ-СІЗ АШУ (ең оңай)
=====================================================
index.html файлын браузерде ашыңыз. Сайт толық жұмыс істейді,
тек ЖИ көмекші дайын үлгі бойынша жазады.

=====================================================
2. ЖИ-МЕН АШУ (ChatGPT немесе Claude API арқылы)
=====================================================
а) Node.js орнатыңыз (18 немесе одан жаңа нұсқа): https://nodejs.org
   Тексеру: терминалда  node -v

ә) API кілтін алыңыз:
   ChatGPT: https://platform.openai.com → Billing (баланс толтыру) → API keys → Create new secret key
   Claude:  https://platform.claude.com → Billing → API Keys

б) .env.example файлын көшіріп, атын .env деп өзгертіңіз.
   ChatGPT үшін ішіне жазыңыз:
       AI_PROVIDER=openai
       OPENAI_API_KEY=sk-...
   Claude үшін:
       AI_PROVIDER=claude
       ANTHROPIC_API_KEY=sk-ant-...

в) Терминалды жоба қалтасында ашып:   node server.js
   «ЖИ қосулы: ChatGPT (OpenAI), модель gpt-6-astra» деген жазу шығуы керек.

г) Браузерде ашыңыз:  http://localhost:3000
   (index.html-ді екі рет басып ашпаңыз, сонда ЖИ қосылмайды.)

Тоқтату: терминалда Ctrl+C.

Модельдер (.env ішінде AI_MODEL / AI_QUICK_MODEL арқылы ауыстыруға болады):
   ChatGPT: gpt-6-astra (негізгі), gpt-6-luna (жылдам әрі арзан)
   Claude:  claude-sonnet-5-5 (негізгі), claude-haiku-5-5 (жылдам әрі арзан)

МАҢЫЗДЫ:
 - .env файлын ешкімге жібермеңіз, GitHub-қа салмаңыз (.gitignore оны өзі алып тастайды).
 - API кілті тек server.js ішінде қолданылады, браузерге берілмейді.
 - API ақылы: әр ЖИ сұранысы балансыңыздан аздап шығын жасайды.

=====================================================
3. ФАЙЛДАР
=====================================================
  index.html          — беттің қаңқасы, CSS пен JS файлдарын қосады
  css/style.css       — түстер (CSS айнымалылары), кабинет, батырмалар
  css/landing.css     — бастапқы бет
  css/calendar-ai.css — күнтізбе және ЖИ көмекші
  js/app.js           — деректер, қазақша/орысша сөздік, кабинет беттері
  js/landing.js       — бастапқы бет және Сыңғыр талисманы (SVG)
  js/calendar-ai.js   — күнтізбе, ЖИ көмекші, API-ге қосылу (makeApiAI)
  js/main.js          — сайтты іске қосу
  server.js           — Node.js сервер: файлдарды береді, ЖИ сұранысын ChatGPT немесе Claude API-ге жібереді
  .env.example        — баптаулар үлгісі

ЖИ қалай жұмыс істейді:
  браузер (calendar-ai.js) → POST /api/ai → server.js → OpenAI / Claude API → жауап → браузер
